# City Builder

Градостроительная игра на Python + pygame-ce.

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py
```

## Управление

| Действие | Клавиши |
|---|---|
| Двигать камеру | Стрелки / WASD, или зажать среднюю кнопку мыши и тянуть |
| Масштаб | Колесо мыши |
| Выход | Esc |

## Структура

```
city_builder/
├── config.py              — константы
├── core/game.py           — класс Game, связывает все части
├── core/game_loop.py      — игровой цикл
├── world/tile.py          — клетка и её тип
├── world/grid.py          — сетка карты
├── render/camera.py       — камера (сдвиг, масштаб)
├── render/renderer.py     — отрисовка
└── input/input_handler.py — клавиатура и мышь
```

## Этапы

- [x] Этап 0 — окно, сетка, камера, подсветка клетки под курсором
- [ ] Этап 1 — строительство (дорога, дом, завод)
- [ ] Этап 2 — экономика (деньги, население, тик)
- [ ] Этап 3 — цель игры
